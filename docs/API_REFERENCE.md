# مرجع کامل اندپوینت‌های API نسخه ۱ (`/api/v1/`) — کاوه ۱۸۵ (`docs/API_REFERENCE.md`)

تمامی مسیرهای API سامانهٔ کاوه ۱۸۵ تحت پیشوند نسخه‌دار `/api/v1/` ارائه می‌شوند و دارای هدر `X-API-Version: v1`، هدر رهگیری `X-Request-ID` و بودجهٔ کارایی `X-Response-Time-ms` هستند.

---

## ۱. اندپوینت‌های عمومی و شرکت‌کنندگان

| متد | مسیر | سطح دسترسی | شرح کاربرد |
|---|---|---|---|
| `GET` | `/api/v1/exam/status/` | عمومی (`AllowAny`) | وضعیت بازهٔ زمانی آزمون (`upcoming` / `open` / `ended`)، پیام وضعیت و قوانین مسابقه |
| `GET` | `/api/v1/mosques/` | عمومی (`AllowAny`) | لیست کشویی ۱۷ مسجد فعال حوزه ۱۸۵ شهید کاوه برای فرم ثبت‌نام |
| `GET` | `/api/v1/mosques/leaderboard/` | عمومی (`AllowAny`) | جدول زندهٔ رتبه‌بندی مشارکت مساجد بر اساس تعداد شرکت‌کنندگان در آزمون |
| `POST` | `/api/v1/auth/register/` | عمومی (`AllowAny`) | ثبت‌نام شرکت‌کننده (نام، نام خانوادگی، کدملی یکتا، موبایل یکتا، تاریخ تولد، مسجد) و صدور توکن |
| `POST` | `/api/v1/auth/otp/request/` | عمومی (`AllowAny`) | ارسال کد تایید ۶ رقمی پیامکی (`OTP`) |
| `POST` | `/api/v1/auth/otp/verify/` | عمومی (`AllowAny`) | تایید کد OTP و دریافت توکن‌های JWT متصل به نشست |
| `GET` | `/api/v1/auth/me/` | شرکت‌کننده (`Bearer`) | دریافت پروفایل کاربر جاری |
| `POST` | `/api/v1/exam/start/` | شرکت‌کننده (`Bearer`) | شروع آزمون ۵ سواله با تصادفی‌سازی دوگانه یا بازیابی جلسهٔ باز |
| `GET` | `/api/v1/exam/current/` | شرکت‌کننده (`Bearer`) | دریافت سوالات آزمون جاری و ثانیه‌های باقی‌مانده از تایمر سرور |
| `POST` | `/api/v1/exam/answer/` | شرکت‌کننده (`Bearer`) | ثبت پاسخ یک سوال (به ترتیب ۱ تا ۵ بدون افشای درست یا غلط بودن) |
| `POST` | `/api/v1/exam/finish/` | شرکت‌کننده (`Bearer`) | پایان آزمون، صدور کارنامه بدون افشای کلید، افزایش امتیاز مسجد و ارسال پیامک تشکر |
| `GET` | `/api/v1/exam/report-card/` | شرکت‌کننده (`Bearer`) | مشاهدهٔ کارنامهٔ نهایی شرکت‌کننده |
| `GET` | `/api/v1/exam/receipt/{tracking_code}/` | عمومی (`AllowAny`) | استعلام اصالت رسید دیجیتال کارنامه با کد رهگیری (`KV185-XXXXXXXX`) |

## ۲. اندپوینت‌های پنل مدیریت (ادمین و اپراتور)

| متد | مسیر | سطح دسترسی | شرح کاربرد |
|---|---|---|---|
| `GET` | `/api/v1/admin/command-center/` | ادمین | نمای یکپارچه ۳۶۰ درجه مرکز فرماندهی ادمین در یک درخواست |
| `GET / PATCH` | `/api/v1/exam/admin/config/` | ادمین | مشاهده و ویرایش زندهٔ تنظیمات آزمون (زمان شروع/پایان، تایمر، OTP، امتیازدهی و پیامک) |
| `GET / POST` | `/api/v1/exam/admin/questions/` | ادمین | فهرست و افزودن سوال چهارگزینه‌ای در بانک سوال |
| `GET / PATCH / DELETE` | `/api/v1/exam/admin/questions/{id}/` | ادمین | مشاهده، ویرایش سوال/کلید صحیح (همراه با بازتصحیح خودکار کارنامه‌ها) و غیرفعال‌سازی |
| `POST` | `/api/v1/exam/admin/questions/bulk/` | ادمین | ورود دسته‌ای سوالات چهارگزینه‌ای |
| `POST` | `/api/v1/exam/admin/questions/seed-defaults/` | ادمین | بارگذاری سوالات نمونهٔ هفته بسیج و شهید کاوه |
| `POST` | `/api/v1/exam/admin/regrade/` | ادمین | بازتصحیح دستی تمامی کارنامه‌های ثبت‌شده بر اساس آخرین کلید سوالات |
| `GET / POST` | `/api/v1/mosques/admin/` | ادمین | فهرست مدیریتی و افزودن مسجد جدید |
| `GET / PATCH / DELETE` | `/api/v1/mosques/admin/{id}/` | ادمین | ویرایش یا غیرفعال‌سازی مسجد |
| `GET` | `/api/v1/reporting/admin/dashboard/` | ادمین | داشبورد آماری زنده (کلی، به تفکیک ۱۷ مسجد، رده سنی و تحلیل دشواری سوالات) |
| `GET` | `/api/v1/reporting/admin/participants/` | ادمین | کاوشگر چندفیلتره و چندمرتب‌ساز شرکت‌کنندگان ویژهٔ مراسم قرعه‌کشی حضوری |
| `GET` | `/api/v1/reporting/admin/participants/{user_id}/` | ادمین | پروندهٔ کامل شرکت‌کننده همراه با ریز ۵ سوال و گزینه‌های انتخابی |
| `GET` | `/api/v1/reporting/admin/export.xlsx` | ادمین | دانلود فایل اکسل ۷ برگی راست‌به‌چپ (`.xlsx`) با قابلیت اعمال تمام فیلترها |
| `GET` | `/api/v1/notifications/admin/sms-logs/` | ادمین | مشاهدهٔ لاگ تحویل پیامک‌های OTP و تشکر پایان آزمون |
| `POST` | `/api/v1/notifications/admin/send-test/` | ادمین | ارسال پیامک تستی یا اطلاعیه قرعه‌کشی |
| `GET` | `/api/v1/audit-logs/admin/logs/` | ادمین | مشاهدهٔ زنجیرهٔ لاگ‌های حسابرسی تغییرناپذیر |
| `GET` | `/api/v1/audit-logs/admin/logs/verify/` | ادمین | بررسی یکپارچگی رمزنگاری زنجیرهٔ هش حسابرسی (`SHA-256`) |
